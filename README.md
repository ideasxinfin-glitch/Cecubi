# CECUBI · Landing de presentación

Demo navegable del colegio CECUBI, con diseño naranja y azul marino, cuatro niveles educativos, instalaciones, vida escolar, admisiones por WhatsApp y propuesta interactiva CECUBI Conecta.

## Abrir la demo

Descarga o clona este repositorio y abre `index.html`. También puedes servir la carpeta con cualquier servidor de archivos estáticos. No requiere dependencias, compilación, backend ni base de datos.

## Contenido

- HTML, CSS y JavaScript de la landing.
- Logotipo recuperado del proyecto original.
- Quince imágenes de muestra generadas con IA, almacenadas en `assets`.
- [Guía de publicación en Vercel](LEEME.md).
- [Inventario de imágenes y sustitución por fotografías reales](IMAGENES-DEMO.md).
- [Propuesta de evolución de la plataforma](PROPUESTA.md).

Las imágenes escolares representan escenas ficticias y se reemplazarán por fotografías reales autorizadas. CECUBI Conecta muestra una propuesta de expansión con contenido de ejemplo; su panel no tiene cuentas ni envío de mensajes.

## Publicación

En Vercel, importa este repositorio como proyecto estático, selecciona **Other** y utiliza la raíz del repositorio. No se necesita comando de compilación ni variables de entorno. Consulta `LEEME.md` para más detalle.

La demo mantiene `noindex,nofollow`. Valida textos, contacto e imágenes antes de convertirla en sitio institucional definitivo.
